### Kairos | Assistente Financeiro Inteligente por Voz

API REST desenvolvida com Java e Spring Boot para gerenciamento financeiro com integração de IA generativa e processamento de áudio.

O projeto utiliza Google Gemini para interpretar informações financeiras e integra persistência com MariaDB.

**Tecnologias:** Java 21, Spring Boot, Spring AI, Gemini, MariaDB, Docker Compose, JPA e Swagger.

### Design Patterns com Java & Spring Boot

**Tecnologias:** Java 21, Spring Boot, Spring Data JPA, OpenFeign, H2, ViaCEP e Swagger.
